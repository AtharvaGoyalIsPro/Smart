Pairing instructions (BLE):
  1. Power the container device. It will advertise a BLE name like SmartContainer-XXXX.
  2. Open your mobile app and connect via BLE.
  3. Send the string: SSID;PASSWORD;YOUR_UID;CONTAINER_ID (no spaces) over the BLE write characteristic.
  4. The device will attempt to connect to Wi-Fi and then start uploading fill % to this container entry.
Quick help

When you create a container, copy the container code to pair the device via BLE. For production, a mobile app should perform BLE write automatically.
